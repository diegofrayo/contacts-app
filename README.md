
# contacts-app

A simple contacts management application built for learning purposes. This project demonstrates how to create a contacts app using two different approaches: plain JavaScript and React. It allows users to add, view, and manage their contacts in a straightforward interface.

## 📁 Sub-projects

- **react/**: This folder contains the React implementation of the contacts app. It leverages modern React features, component-based architecture, and tools like Tailwind CSS for styling. Ideal for learning how to build scalable and maintainable applications with React.

- **vanilla-js/**: This folder features the same contacts app built with plain JavaScript, without any frameworks. It focuses on fundamental web development concepts, DOM manipulation, and basic state management, making it perfect for understanding the core principles behind web apps.

- Strategy pattern for data management | **[Example 1](https://github.com/diegofrayo/contacts-app/tree/main/vanilla-js/src/modules/data/contacts)** - **[Example 2](https://github.com/diegofrayo/contacts-app/tree/main/vanilla-js/src/modules/events-manager)**
